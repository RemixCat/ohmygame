# 画板图片快捷操作

从图片输出端拉线到空白处，或右键点击图片节点，即可打开快捷操作菜单。
连到已有节点时仍按原有逻辑建立引用。选择菜单只创建节点，不会立即发起生成请求。

- **生成描述 / 推测提示词**：创建关联参考图的文本节点，选择支持看图的语言模型并运行，
  结果可以直接编辑。这是根据图像推测的描述，无法恢复原始提示词。
- **识别图片内物体**：先运行识别，得到最多 16 个物体。可以修改名称、描述和提示词，
  然后勾选要生成的素材。只有勾选的物体会创建独立图片节点并生成。识别本身不会生成图片。
- **生成三视图**：创建一个文本控制节点及俯视、正视、右视三个普通图片节点。
  在控制节点编辑共享主体描述 / 风格，各视角的提示词可以分别修改，再点击“运行三视图”。
- **根据参考图生成图片 / 生成 3D 模型**：创建已经连接参考图的现有节点，
  通过节点原有的参数和生成按钮运行。

## 默认模型

批量图片生成优先使用项目指定的默认图片模型，否则使用“设置 → 服务商与模型”里的
默认图片模型。批次默认显示“使用默认模型”，执行时读取当前选择，
不会固定使用创建节点时的旧模型。提交前会把实际选择写入每个输出节点。

如果需要，可以单独为某个批次选择模型；选回“使用默认模型”即可恢复继承设置。
没有默认模型时，界面提示配置并禁用生成，不会自动挑选列表第一项。
模型不可用或不支持参考图片时也会显示明确提示。尺寸选项跟随模型支持范围。

描述和物体识别使用支持图片输入的**语言模型**；绘制素材和三视图使用**图片模型**。
鉴权失败、取消 / 超时和输出截断会保留具体错误，方便排查。

## 任务与保存

批次最多同时运行两个生成任务，等待任务结束后才释放名额。
画板已有生成任务时需等它完成再启动批次。重复点击不会重复提交。
某个物体或视角失败不会丢失其他成功结果，可以只重试失败 / 取消项，也可以单独重试。
取消会停止队列并按现有服务商能力请求取消已提交任务，不保证远端立即停止或退费。

离开画板会停止未提交项的本地排队，已提交任务仍保留在历史里。
再次打开时，节点、引用、设置、物体勾选、已提交任务状态和结果文件可恢复；
未提交项恢复为“待运行”。创建的一组节点可以一起撤销，但撤销节点不会撤销已经发出的模型请求。

每个生成结果是独立文件，以节点名称保存，沿用素材库与项目副本机制。
左侧 Agent 可以继续读取、编辑和运行这些普通文本、图片、3D 节点。
`quickAction` 是可选的节点元数据，保存来源、分组、物体勾选和共享设置。
不识别该元数据的旧版程序不应编辑新画板。

## 效果范围

独立物体是参考原图重新绘制，首版不做保留原像素的精确抠图。
透明背景、三张视图的几何一致性取决于模型能力；原图看不到的部分由模型推测。
重新识别会产生新的物体清单，之前的结果节点和文件继续保留。
当前提供固定快捷操作，不自动执行整张依赖图。
