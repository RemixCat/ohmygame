# 为已有项目选择工作区

[English](project-workspace.md)

在项目列表、首页或工作室入口的项目卡片上，点击 **… → 选择工作区**。
检查当前路径，通过桌面文件夹选择器选择目录，再点击**使用此文件夹**。
取消选择器或弹窗不会修改项目。此入口需要桌面应用，普通浏览器无法调用原生文件夹选择器。

保留项目 ID、类型、名称、设置和对话。这只更改工作区引用，不会移动、复制或覆盖源文件。
请选择实际准备使用的文件夹。如果要搬迁已有游戏，请先自行把文件复制到目标目录，再切换引用。
预览启动设置会保留，新目录布局不同时可能需要调整。原预览会停止，不会自动执行新目录。

请先结束 Agent、生成和发布任务。正在执行的文件写入会先完成；旧编辑器继续提交的保存会被拒绝。
如果存在中断的文件恢复，需先完成恢复。切换后其他打开的项目视图会重新加载，
Agent 会话也会基于新目录重新初始化。

切换时拒绝文件系统根目录、不存在的目录、符号链接、OhMyGame 内部项目存储目录，
以及与其他项目工作区重叠的目录。旧工作区已丢失或搬走时，可以重新选择它的新位置。
再次选择当前目录不会改变项目。

文件快照属于一次工作区选择。每次实际切换都启用新的快照存储；旧对话快照仍保留在磁盘上，
但不能恢复到新目录。切回原路径也会重新记录快照。旧对话中的文件引用和附件可能仍指向原目录，
继续工作前应检查当前文件。

可选元数据字段 `workspaceCheckpointId` 标识快照存储。已有项目未切换时继续使用原来的
`checkpoints` 存储。新路径和存储标识通过同一次原子 `project.json` 更新持久化。
工作区通知和版本检查会拒绝旧编辑器向新目录保存，即使退出发生在后续通知写入之前。

后端接口为 `PUT /projects/:projectId/settings/workspace`，请求体为
`{"workspacePath":"/absolute/folder"}`，并携带读取项目后获得的 `x-workspace-version`。
返回更新后的项目和版本。工作区忙碌或版本过期返回 HTTP 409。
这是单个项目的设置，不会改变应用的全局数据目录。
