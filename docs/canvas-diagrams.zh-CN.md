# 思维导图与拓扑图

[English](canvas-diagrams.md)

设计画板和素材画布支持原生图表主题，可与文档、图片、音频和制作流程放在同一画板上。全部本地运行，无需服务商密钥和生成费用。功能分支为 `feat/canvas-diagrams`；本机预览分支还包含独立的工作区选择、SpriteCook 与 Studio 界面改动。

参见[主题关联画板](canvas-board-links.zh-CN.md)，将规划主题作为详细画板的导航入口。

## 创建与编辑

1. 点击画板底部 **添加节点 → 思维导图 / 拓扑图**，或使用空白处右键菜单中的相同入口，创建中心主题与两个分支。
2. 双击主题，或聚焦主题后按 **空格 / F2** 编辑。**Enter** 确认，**Shift+Enter** 换行，**Escape** 恢复本次编辑前的文字。输入内容会在离开输入框前参与自动保存。
3. 聚焦已选主题后，按 **Tab** 添加子主题，按 **Enter** 添加同级主题，也可以使用卡片按钮。**Shift+Tab** 保留正常焦点导航。新主题超出视野时，画面自动跟随。
4. 从主题右侧端口拖到其他主题左侧端口，也可使用画板已有的整卡吸附。支持跨分支关系与循环；同一方向的重复连线会被忽略。
5. 点击选中主题的 **… → 图表工具**，修改颜色、形状、关系说明与方向箭头。双击关系线可直接打开对应编辑项；相互指向的两条关系说明会错开放置。

## 整理与导出

**树状整理** 按生成树展开主题；**拓扑分层整理** 按广度遍历分层，并把同层互相关联的主题放在相邻位置。两者都保留全部连线、循环与共享子节点，只整理当前连通图，不移动其他图表或媒体，并自动适应视图。复杂图可继续手动拖动节点改善走线。

**添加独立主题** 可开始另一张图。导出仅包含当前连通图：

- **Mermaid**：保留文字、关系说明、有向与无向连线，文字经过转义。
- **Markdown**：主题清单与关系清单，保留交叉和循环关系。

可复制预览或下载 `.mmd` / `.md` 文件。首版未包含导入、图片/SVG 导出、专属分支折叠、完整的正交避障走线或 XMind 兼容。可使用现有画板分组来组织和折叠主题。删除主题会清理其关联线，保留其他主题；选中、复制、分组、撤销和重做沿用画板已有机制。

## 保存与 Agent

主题类型为 `topic`，包含 `data.text`（最多 2000 字符），可选颜色 `blue / green / orange / purple / gray`，可选形状 `card / rounded / pill`。关系线使用 `kind: "diagram"`，支持 `label`（最多 200 字符）和 `directed`（默认有向）；两端必须是不同主题，输出端口为 `sourceHandle: "out"`。坐标保存在编辑器布局，卡片尺寸为 224 × 128。

这些关系用于描述图表，不作为生成依赖，也不能把主题接入媒体生成输入。原有提示词与参考连线的含义保持原样。图表沿用画板校验、版本冲突保护、自动保存和撤销恢复，遵循每板 2000 节点、8000 连线的上限。Agent 可通过普通文件工具与 `canvas_check` 编辑；应用维护的说明和 Schema 已补充图表约定，保留自定义 Agent 指令。

旧版本无法识别主题节点，降级前应备份画板及布局文件。
