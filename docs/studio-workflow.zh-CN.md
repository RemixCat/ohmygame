# 素材管理、项目规范与制作模板

项目中新增与画板、代码、素材并列的**规范**入口。素材库采用收藏夹、标签、素材网格和详情布局；窄窗口把分类与详情收进抽屉。

## 素材组织与项目决策

收藏夹支持嵌套，一个素材可属于多个收藏夹。删除收藏夹保留素材，子收藏夹提升到上一级。支持标签、收藏、说明和来源，搜索与类型、来源、项目引用、标签、用途、审阅和系列筛选取交集；多标签可选全部或任一符合。智能收藏夹保存筛选条件，每次根据当前素材重新计算。

全局信息保存在数据目录的 `library/organization.json`；项目用途、视觉审阅、规格检查、接入证据和选定版本保存在项目的 `canvas/production.json`。编辑项目决策必须选择具体项目；“项目引用筛选”单独控制网格范围。同一图片可在一个项目中作为淘汰参考，在另一项目中作为已认可设计稿。画板引用不代表接入游戏，“有证据验证”必须填写验证证据。

多选可批量修改标签、收藏夹、用途与审阅，点击“保存修改”写入磁盘。未保存草稿在本地保留原磁盘版本，恢复时不会覆盖其他编辑器的新修改；旧版本写入返回 409。“从磁盘重新加载”会在确认后丢弃草稿。

版本系列可新建、重命名、手动归并或移出；同一节点重新生成的结果自动归入同一系列。每个项目独立选定当前版本，选定不替换代码或旧画板引用。两张图片可同步缩放比较并查看生成依据。

## 项目规范

内部导航包含美术方向、UI 与交互、素材规格、提示词与模板、验收标准。每个方案有草稿和不可改写的已启用版本；保存草稿不影响当前生成，启用会增加版本，可指定项目默认。

方案继承顺序为项目默认、父组、子组、节点显式选择；各部分的局部覆盖按父组到节点依次应用。生成预览使用已保存节点解析最终提示词、参考素材和实际参数，不提交生成。任务与素材保存完整快照：原提示词、最终提示词、规范版本和内容、局部覆盖、模板版本和内容、参数、参考 ID 与图片内容摘要。失败重试沿用已准备提示词与快照，不重复追加规范。

画板、批次和 Agent 媒体工具共用解析逻辑。方向和输出要求作为文本约束，传入服务商的参数沿用其已有支持范围。规格需要生成后检查；规格检查、视觉审阅、接入证据分别呈现。Agent 每轮读取已启用方向，沿用现有共享样式；修改规范本身不改写游戏代码。

## 嵌套分组与多画板

“分组与模板”面板支持所选节点成组、命名、颜色、父组、移入移出、复制、折叠、解组。拖动组标题整体移动后代。节点只有一个直接组，组只有一个父组，禁止循环。折叠仅把跨组线显示到边界，内部节点与真实引用继续保存。解组保留内容并提升到父级，“删除组及内容”为独立操作。操作纳入画板撤销、重做和版本冲突恢复。

分组将画板升级为格式 2，语义信息在画板文件中，坐标与折叠状态在编辑器布局中。首次升级前保留画板及布局的 `<id>.v1-backup.json`；旧格式 1 仍可读取。

独立素材画布开放与游戏项目相同的多画板创建、切换、排序、重命名与删除。删除画板保留文档、表格、素材和任务；至少保留一张画板。

## 制作模板

提示词变量包含名称、说明、默认值与必填标记，可复制已填写提示词或插入文本节点。流程模板从嵌套组保存，保存前列出文档、表格、素材引用和待绑定输入。旧生成结果与任务记录不携带；Markdown 本地图片保存到素材库，插入时重绑目标项目路径。媒体输入选择素材，文本输入填写文本，内部文档与表格分配新 ID。

内置物体三视图、角色参考表、参考图到 3D、UI 图标四种起点。插入重新分配组、节点与连线 ID，只创建流程，不自动执行。模板跨项目复用并保留旧版本，修改模板不影响已插入实例。

## 接口与校验

- `GET/PUT /library/organization`：全局组织、版本系列、素材信息、模板，使用 `{value, revision}`。
- `GET/PUT /projects/:id/production`：项目规范、审阅与选定版本，同样进行版本冲突保护。
- `POST /library/studio/query`: `{filter, projectId?}`.
- `POST /library/studio/batch`：素材 ID、保存版本，以及全局组织或项目审阅修改。
- `POST /projects/:id/studio/capture`：从已保存组获取模板，审阅依赖后保存。
- `POST /projects/:id/studio/insert`：模板 ID、目标画板、变量、输入与画板版本。
- `POST /projects/:id/canvas/boards/:board/nodes/:node/production-preview`：复用生成解析，不提交请求。

JSON 写入串行并使用原子替换，Schema 校验非法字段、层级和引用。`canvas_check` 覆盖分组与规范引用，应用维护 `canvas/schemas/production.schema.json`；升级生成的文件说明时保留用户自定义 AGENTS。

颜色搜索、相似图查重、网页采集、自动 AI 打标签暂不包含。真实模型效果与游戏接入需配置服务商并实际审阅，模拟测试不能替代这些验收。
