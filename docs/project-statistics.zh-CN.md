# 对话消耗与项目统计

[English](project-statistics.md)

独立贡献分支 `feat/project-usage` 基于 `studio`，通过本地保留的会话文件与项目元数据
提供统计，不依赖思维导图或 SpriteCook 分支。集成预览也包含本功能，本次不发布独立安装器。

## 使用入口

- AI 输入框下方显示当前会话累计 token、输入（含缓存读取／写入）、输出、按 token
  计算的缓存命中率，以及已有 SDK 费用估算。点击摘要可看会话明细和最近一次记录。
- 摘要旁的「项目统计」打开项目报告；首页和项目列表的项目「…」菜单也有此入口。
- 可切换当前对话／整个项目，选择今天、近 7 天、近 30 天或自定义起止日期。
  起止日期均计入，按浏览器所在 IANA 时区统计，界面会显示时区。
- 项目报告包含按模型／服务商、对话、日期汇总，已返回的顶层工具调用与错误，
  响应明细及当前画板内容。响应明细包含成功／失败／中止、输入／输出／缓存、
  总 token、已有推理明细、费用估算和响应耗时。
- 「导出 JSON」保存所选范围与日期内的汇总及已有明细；「导出响应 CSV」保存响应明细，
  包含用量、估价是否可用的明确字段。明细与导出最多保留最近 500 条响应，每页 50 条，
  汇总／模型／日期数据仍统计全部保留记录。

![输入框下方的会话用量](assets/conversation-usage-footer.png)

底栏在切换会话和运行状态变化时刷新，运行时约每 3 秒、空闲时约每 30 秒读取一次；
页面隐藏时降低频率。用量在响应保存后出现，流式文字不能提供可靠的实时 token 数。
读取失败时显示不可用／重试，或注明显示上次快照，不伪造零消耗。
项目报告在打开、筛选或手动刷新时更新。

## 统计口径

| 指标           | 定义                                                                |
| -------------- | ------------------------------------------------------------------- |
| 未缓存输入     | Pi 标准化后的 `usage.input`                                         |
| 输出           | `usage.output`，包含服务商记入其中的推理 token                      |
| 缓存读取／写入 | Pi 标准化后的 `usage.cacheRead`／`usage.cacheWrite`                 |
| 总 token       | 未缓存输入＋输出＋缓存读取＋缓存写入                                |
| 缓存命中率     | 缓存读取÷（未缓存输入＋缓存读取＋缓存写入）；没有已记录输入时不可用 |
| 推理 token     | 服务商可选返回的输出子集，不再次加进总 token                        |
| 估算美元费用   | 历史响应保存的 SDK 模型价格表正值估算，可展开查看分项               |
| 估价覆盖       | 有正值估价的响应／已记录响应；混合覆盖时标为“部分”                  |
| 响应耗时       | 已记录 `durationMs` 的累计；平均值只使用有耗时的响应                |
| 工具记录／错误 | 已保存的顶层工具返回记录及 `isError`，不计从未返回的调用            |
| 上下文压缩     | 保留的压缩记录次数，不推算摘要生成费用                              |

Pi／服务商适配器可能将缺失缓存字段补为 0，所以缓存命中率仅反映记录中的 token 比例，
不代表请求命中率、必然节省的费用或服务商后台账单。旧记录缺少四类 token 中任一类时，
标为缺少用量且不计入 token 汇总；缺失的推理／耗时保持未知。费用为 0 时视为未定价，
因为自定义服务商、免费／订阅套餐及缺少价目表时也可能保存 0。

统计读取**全部保留的会话记录，包括非当前分支**，回退与压缩不会抹掉已记录消耗。
项目汇总按服务商／模型／响应 ID 去重；没有响应 ID 时按复制记录的 ID／时间去重。
共享记录归入较早创建的对话。单会话报告包含自己保留的共享历史，因此可能与该会话在
去重后的项目报告中的行不同。不同重试、失败／中止但已记录用量的响应仍计入。

本功能不是独立记账账本。已删除／无法识别的会话文件、压缩摘要调用、画板直接文生内容和
外部调用可能没有可用的保留用量。工具明确上报的自身用量也会计入，没有模型元数据时归入
工具分组。媒体生成按任务数统计，不推算 token、积分或费用；计算统计不会请求服务商账单，
也不会发起生成调用。

## 项目内容与数据范围

项目内容页显示已保存的画板、文档、表格、登记素材、节点、连线、分组和节点类型分布。
这是**当前快照**，不受日期筛选影响。它统计登记素材，不扫描所有文件、计算磁盘体积，
也不据此判断游戏功能是否完成。生成任务数按所选日期统计，将属于当前项目的全局任务与
画板任务历史按任务 ID 合并，仅覆盖保留历史。

可识别但读取失败的会话／画板会标明统计不完整，缺少画板数据与 AI 零记录分开显示。
读取不会创建画板、提交任务、改写会话文件或扫描整个代码仓库。
切换项目工作区会改变内容快照，token 历史仍跟随该项目的会话存储。

导出不包含消息正文、工具参数／结果、凭据和绝对路径；包含对话标题（可能来自第一条提示词）
和模型／服务商标识。CSV 单元格加引号，对公式前缀标识进行转义。
JSON 采用同一份只包含统计元数据的 API 契约。

## 代码与接口

- `src/shared/project-usage.ts`：统计类型和缓存比例。
- `src/daemon/project-usage.ts`：只读聚合和项目接口。
- `src/renderer/project-usage.tsx`：底栏、筛选、指标、明细和导出。
- `GET /projects/:projectId/conversations/:conversationId/usage`：会话累计及最近记录。
- `GET /projects/:projectId/statistics?timezone=Asia%2FShanghai&from=2026-10-01&to=2026-10-31`：
  项目报告；可选 `conversationId` 切换为单会话保留历史。

接口沿用 daemon 认证与项目检查，设置 `Cache-Control: no-store`，不返回会话路径或对话标题
以外的消息内容。非法日期／时区返回 400，项目或会话不存在返回 404。查看统计不需要模型密钥。

自动化测试覆盖 token 算法、未知字段、推理、历史／共享记录、日期时区边界、明细数量限制、
错误／取消、范围切换、隐私、文件不被改写和重试。实际界面使用可丢弃的本地验收数据，
截图不包含用户项目、凭据或付费生成结果。具体检查结果记录在贡献 PR。

贡献分支本地验收：插件准备（下载失败后重新校验已有固定版本缓存）、更新日志、类型检查、界面／sandbox 构建及 Node daemon/player 启动检查通过。单 worker 全量测试 **2,902 项通过、23 项预期跳过**。此前双 worker 运行触发已有的预览启动 1.5 秒耗时断言（实际 2.173 秒），随后相关 16 项测试和单 worker 全量测试通过。实际界面已验证底栏、项目卡片入口、范围／日期快捷筛选、部分／未知估价、明细，以及 360／520／720／1200 像素布局；实际下载的 CSV、JSON 合计与验收记录一致。
