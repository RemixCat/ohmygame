# 从规划主题跳转到详细画板

[English](canvas-board-links.md)

用[思维导图](canvas-diagrams.zh-CN.md)梳理整个游戏，把内容较多的主题关联到
当前项目里的详细画板。设计工作区和素材画布均支持，不需要服务商或生成积分。

## 使用方法

1. 选中主题，点击「关联画板」（图表工具旁的箭头图标）。选择「已有画板」，
   或填写「新画板名称」后点击「新建并关联」。默认名称取自主题，最多 120 字符。
2. 关联或新建后会留在总览。点击主题里的画板快捷入口即可打开详细画板；
   双击主题文字仍然用于编辑文字。
3. 点击画板选择器旁的「返回 …」回到来源。跳转前会保存当前编辑内容，
   每个画板恢复各自保存的位置与缩放。
4. 再次打开「关联画板」可以改绑或「解除关联」。解除关联和删除主题都不会删除
   目标画板；这些主题编辑支持现有的自动保存和撤销／重做。

例如：「游戏总览 → 钓鱼玩法 → 鱼类行为」，另一个「UI」主题也可以关联
「钓鱼玩法」。关联不代表文件归属，多个主题可以共用画板，画板之间允许循环跳转。
项目最多支持 100 个画板，从主题新建也计入这个限制。

## 导航与异常恢复

- 返回历史属于当前工作区会话，最多记录 50 次跳转；切换素材画布内部的画布／代码视图
  时保留，刷新页面、离开设计或工作区后清空。手动选择画板、从选择器新建画板会开始新路线。
- 保存失败或查询目标失败时留在当前画板，并显示错误。连续点击不会产生并发跳转。
- 返回时会跳过已删除的来源。如果来源全部删除，触发返回后清空历史并提示画板不可用。
- 改名后，快捷入口和返回按钮通过工作区索引显示最新名称，关联本身使用 ID。
  目标删除或不可用时会保留可修复的入口，点击后可改绑或解除关联，不自动替换或删除内容。
- 在同一项目复制主题时保留关联；复制到其他项目后保留来源身份，显示「请重新关联」，
  不会打开其他项目中的画板。复制或导出项目导致项目 ID 改变时，也可能需要重新关联。
- 新建画板与保存主题是两步操作。如果随后主题保存失败或撤销关联，新画板仍保留在
  选择器里，请通过「已有画板」重新关联，避免重复创建。创建本身失败时保留名称供重试。

## 文件格式与范围

主题的可选字段保存项目范围内的导航引用：

```json
{
  "text": "钓鱼玩法",
  "boardLink": { "projectId": "project-id", "boardId": "board-id" }
}
```

画板 ID 遵循画板索引的 ID 规则，不保存画板名称、绝对路径或回调函数。
关联与图表关系连线、生成引用互相独立。没有关联的旧主题无需迁移。
自动生成的画板 schema 和说明会包含该字段，自定义项目说明保留。
旧版本 schema 可能不接受新字段，使用旧版打开前请备份项目。

当前每个主题支持一个当前项目内的画板关联。暂未实现外部网址、跨项目打开、
定位某个节点／文档、自动反向引用和持久化导航历史。Mermaid／Markdown 导出描述
图表本身，项目内导航关联保存在原生画板 JSON 中。
